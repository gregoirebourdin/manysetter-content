# Retours de validation

> Chaque retour du fondateur devient ici une règle datée, **avant** de corriger le post.
> Ces règles priment sur le guide expert et sur la méthode source. On les relit avant chaque production.

Format d'une règle :

```
## AAAA-MM-JJ · <post concerné>
- Retour : <ce que le fondateur a dit, mot pour mot si possible>
- Règle : <la règle générale qu'on en tire, applicable aux posts suivants>
```
